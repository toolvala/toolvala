How to use the whole school timetable generator

  1. School: enter the school name, and the UDISE number if you want your work saved on this device.
  2. Days, periods and timings: choose the working days, periods per day, first period start time and default minutes. Set the short break, lunch break and any custom breaks. Tick "Periods have different lengths" if the periods are not all the same.
  3. Classes: use "Quick add" to add a range such as 5th to 12th in one tap. With the Arts, Science and Commerce box ticked, 11th and 12th are added once for each faculty. Use "Add one class" for a custom class such as B.A. First Year.
  4. Subjects: pick a day, then fill the subject of every class in every period. Copy that day to all days and change only what differs.
  5. Print: choose one day or all days (one page per day), then tap Generate and download the PDF or PNG, or print. Tap Save to keep everything on this device.

How to use the custom fields

  • Custom class: add a class, choose "Custom (type it)" and type its name.
  • Faculty: for 11th, 12th and custom classes, choose Arts, Science, Commerce or a custom faculty. It prints after the class name.
  • Custom break: add a name, the period it comes after and its minutes. The later periods move automatically.
  • Class teacher: optional. It prints in small text under the class name.

Frequently asked questions

Can all classes be on one page?

Yes. Each page shows every class in rows and the periods in columns for one day. Choose all days to get one page per day.

Can I add 11th and 12th with Arts, Science and Commerce?

Yes. Quick add can create a row for each faculty, and you can add custom classes and custom faculties yourself.

Is my data uploaded anywhere?

No. Everything is created in your browser. Saved work stays on this device, and the erase button removes it.
